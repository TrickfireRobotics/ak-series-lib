# ak-series-lib

Motor library for the AK series motors. This library provides a set of tools and utilities to interface with and control AK series motors in various robotics applications.

## Documentation

**Full documentation is at [docs.trickfirerobotics.com/ak-series-lib](https://docs.trickfirerobotics.com/ak-series-lib)**

- [Getting Started](https://docs.trickfirerobotics.com/ak-series-lib/setup/getting-started/) - developer environment setup
- [Protocol Overview](https://docs.trickfirerobotics.com/ak-series-lib/guides/overview/) - protocol and message structure
- [Code Overview](https://docs.trickfirerobotics.com/ak-series-lib/reference/overview/) - code structure and organization
- [CAN Layers](https://docs.trickfirerobotics.com/ak-series-lib/reference/can-layer/) - CAN bus communication layers
